# Gabriel Moura · Portfólio

Portfólio pessoal de Gabriel Moura, Engenheiro de Dados com experiência em Google Cloud Platform.

**Live:** https://gabriel-moura-portfolio.vercel.app/

## Stack

- HTML5 semântico, single-page
- [Tailwind CSS](https://tailwindcss.com/) via CDN
- Vanilla JS (Intersection Observer para scroll reveal, mobile menu)
- Google Fonts: Plus Jakarta Sans · Inter · JetBrains Mono

## Estrutura

```
portfolio/
└── index.html   # página única com todas as seções
```

## Seções

- **Hero** — headline, CTAs, decoração animada
- **Sobre** — bio + métricas
- **Trajetória** — timeline cronológica (estágios → efetivação)
- **Tech Stack** — GCP, Data Engineering, DevOps, Databases
- **Projetos** — cards Problema / Solução / Impacto
- **Contato** — Email, LinkedIn, GitHub
